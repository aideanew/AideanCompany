# 用户操作手册（控制台当前版本可用部分）

> 本手册只描述当前可用的 HTML 页面能力，不承诺 Runner/自动 CLI/持久化恢复。
> 未知能力不会出现在本手册。

## 1. 安全第一

1. 不要把 Key 粘贴到任何对话框、任务详情、报告、日志。
2. 不要直接编辑 `fleet/console/state/*.json`。
3. 看到 `integrity_fail` 非空时，停止收口，先备份。

## 2. 启动顺序（当前）

1. 打开 PowerShell。
2. 进入 `E:/Code/AideanCompany`。
3. 运行 `python fleet/tools/restart_console_v3.py --console-only`。
4. 打开 `http://127.0.0.1:5000`。
5. 检查 `/api/health` 的 `version` 是否为 `3.1.0-launchbus`。
6. 若网关离线，到角色页启动角色，等待端口监听通过。

## 3. 当前页面能力边界

- 任务页可派工、验收、送审、返工、收口。
- `dispatch_reply` 只证明控制台调用了 Hermes，不能证明 CLI 执行。
- 普通 `DONE` 仍需对照 transcript、证据、reviewer 判定手工复核。
- `grep:<任务包文档>` 类验收只能算中间探针，不能算产品交付。

## 4. 阻塞处理

- `dispatch_blocked_offline`：先启动对应角色。
- `dispatch_blocked_dependency`：先完成前置任务。
- `review_blocked_offline`：先启动 reviewer。
- `integrity_fail`：导出 `tasks.json` + `audit.log`，转人工处理。
